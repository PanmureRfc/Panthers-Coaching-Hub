# Panmure Panthers — U10 / P5

Everything for the age group in one place. Season 2026/27.

---

## docs/ — for the coaches to read

**`1-Coaches-Pack.md`**
The laws we play to, how we coach, who does what, and the session shape. Start here. This is the one to send round when a new coach joins.

**`2-Games-and-Drills.md`**
Every game and drill written up the same way: what it's for, how to set it up, what to say, and how to make it harder or easier. Includes the SRU Wee Games adapted for U10.

**`3-Session-Plans.md`**
Six ready-made Sundays with the tackle progression running through them, plus a blank template.

## app/ — the coaching app

Ready to upload to GitHub Pages. **Read `app/README.md` first** — it's written as steps.

Short version: upload the files, turn on Pages, then add Supabase so all coaches share the same data.

`source.jsx` is the uncompiled source, kept for future changes. It isn't needed to run the app.

---

## Where things live

The app and the docs cover the same ground. The app is the live tool; the docs are what you hand someone who wants to read it properly.

If a drill changes, **change it in the app** — that's what people will actually open on a Sunday. Update the docs when you get round to it.
